# Тестирование

Автотестов в репозитории нет (`package.json` без `test`, нет `*.test.ts` / `*.spec.ts`). Проверка — ручная.

## Редактор

1. Первый запуск создаёт владельца; повторный setup возвращает ошибку.
2. Логин с неверным паролем — сообщение на русском, без входа.
3. Поиск города: 1 символ — пустой список; 2+ — подсказки; выбор строки заполняет координаты и timezone.
4. GPS только после кнопки **«Определить по GPS»**.
5. Макет, который не лезет в 2 ряда, не сохраняется (Zod + `layoutFits`).
6. Несохранённый превью не должен попасть на устройство: откройте PNG в новой вкладке до и после **«Сохранить изменения»**.
7. **«Заменить»** slug: старый `/d/…/screen.png` даёт 404.

## Кадр устройства

1. `GET /d/{slug}/screen.png` — `Content-Type` image/png, размер 800×480 при дефолтном пресете.
2. С `If-None-Match` равным свежему ETag и включённым кешем — 304.
3. С query датчика и карточкой `sensor` на макете — числа на кадре, не демо из редактора.
4. Заголовок `X-Next-Refresh-Seconds`: днём = `refreshMinutes * 60`; ночью при включённом окне = ночной интервал × 60.

## Прошивка

Сверьте тот же slug на Serial Monitor 115200: загрузка PNG, deep sleep, при неизменной погоде — `Screen unchanged (ETag)`.
