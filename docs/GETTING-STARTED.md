# Начало работы

Связанные файлы: [README.md](../README.md), [CONFIGURATION.md](CONFIGURATION.md), [UI.md](UI.md).

## 1. База и приложение

Задайте `DATABASE_URL` (PostgreSQL) и примените миграции:

```bash
npx prisma migrate deploy
npm run dev
```

Прод: [weather-e-ink.vercel.app](https://weather-e-ink.vercel.app/).

## 2. Первый владелец

Если таблица `User` пустая, открывается **«Первый запуск»**: логин ≥ 3 символов, пароль ≥ 8. Создаётся пользователь и панель со случайным `slug` и `DEFAULT_LAYOUT`.

Если пользователь уже есть — форма **«Вход в панель»**.

## 3. Настройте кадр

1. В **01 — Экран** выберите город из списка (не оставляйте только набор текста).
2. Язык, единицы, тема, шрифт, рамки.
3. В **02 — Плата** задайте интервал обновления и ночное окно. Для этой прошивки: разрешение **800×480**, цвета **чёрный / белый**.
4. На превью перетаскивайте карточки и жмите **«+ Добавить карточку»**.
5. **«Сохранить изменения»** — иначе устройство получит старый макет.

## 4. Подключите плату

Скопируйте URL из **03 — Ссылка устройства** в `DEVICE_BASE_URL` прошивки. Без завершающего слэша и без `/screen.png`.

Прошивка: репозиторий elink, см. его README.

## 5. Проверьте PNG

Ссылка **«Открыть PNG ↗»** открывает `/d/{slug}/screen.png` без датчика платы. Живые BMP/BME и заряд появятся только в запросе ESP32.
